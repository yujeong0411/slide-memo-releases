# SlideMemo

화면 가장자리에 붙어 있다가 누르면 펼쳐지는 Windows 메모장이에요.

소개와 사용법은 블로그에 있어요: https://nursecoder.vercel.app/tools/slide-memo

## 다운로드

1. 오른쪽의 [Releases](https://github.com/yujeong0411/slide-memo-releases/releases)에서 최신 버전을 열어요.
2. `SlideMemo-Setup.exe`를 받아 실행하면 설치돼요.

- 바로 받기: [SlideMemo-Setup.exe (최신 버전)](https://github.com/yujeong0411/slide-memo-releases/releases/latest/download/SlideMemo-Setup.exe)
- 지원: Windows 10, 11 (64비트)
- 이미 쓰고 있다면 새 버전이 나올 때 앱이 알려 줘요. 쓰던 메모와 설정은 그대로 이어져요.

### 설치가 막힐 때

아직 코드 서명이 없어서 Windows가 설치를 막을 수 있어요.

- 'Windows의 PC 보호' 창이 뜨면 [추가 정보]를 누르고 [실행]을 눌러요.
- '오류 4551' 또는 '스마트 앱 컨트롤이 차단했어요'가 뜨면 스마트 앱 컨트롤이 막은 거예요. Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤에서 끄면 설치할 수 있어요. 보안 기능이라 끄기 전에 한 번 더 생각해 주세요.
- 회사 PC에서 막히면 전산 담당 부서에 문의해 주세요.

이 저장소에는 설치 파일만 올려요. 메모는 내 컴퓨터에만 저장되고, Google Drive 동기화는 설정에서 직접 연결했을 때만 내 Drive의 앱 전용 공간에 보관돼요. 자세한 내용은 [개인정보처리방침](https://nursecoder.vercel.app/tools/slide-memo/privacy)에 있어요.
